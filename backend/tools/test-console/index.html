手机直接切换，无需连接电脑

  1. App → 设置，连续点击底部版本号 7 次。
  2. 打开环境面板，点击测试环境旁的 ⓘ，选择“进入测试环境”。
  3. 添加测试行程并开启实时活动，再锁屏。在这里改延误、到站状态，后台会向设备推送。

测试环境使用独立数据。此面板公开、共享，修改会影响连接这个环境的测试设备。
